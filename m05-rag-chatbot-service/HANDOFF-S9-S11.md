### 2-2. 배포본에서 로컬 Ollama — 관문이 둘이고 `OLLAMA_ORIGINS` 로는 못 넘는다

포트 11435 에 `OLLAMA_ORIGINS` 만 설정한 **두 번째 인스턴스**를 띄워 갈랐다(검증 후 종료).
사용자 환경변수와 떠 있는 Ollama 는 건드리지 않았다.

| 검사 | 결과 |
|---|---|
| 프리플라이트 `http://localhost:5173` → 11434 | 204 + `ACAO: http://localhost:5173` |
| 프리플라이트 배포본 origin → 11434 (미설정) | **403** (프리플라이트도, 실제 GET 도) |
| 프리플라이트 배포본 origin → 11435 (설정) | **204 + `ACAO: https://ibiseolsin.github.io`** |
| `Access-Control-Request-Private-Network: true` | `Access-Control-Allow-Private-Network` **안 보냄** |
| 브라우저 `fetch` 배포본 origin → 11434 · 11435 | **둘 다 `net::ERR_BLOCKED_BY_CLIENT`** |
| 브라우저 `fetch` `localhost:5173` → 11434 | 200 |

**① CORS 는 README 안내대로 열린다. ② 그런데 브라우저가 요청 자체를 막는다** — 설정을 고친
인스턴스도 막혔고, 같은 브라우저에서 로컬 origin 은 붙는다. **차단 주체는 단정하지 못했다**:
에러가 크롬의 사설망 전용 코드가 아니라 `ERR_BLOCKED_BY_CLIENT` 였고 관측이 에이전트 조작
크롬이다. **사람 크롬 재확인 항목**으로 README 에 남겼다.

곁가지 둘: Ollama 는 허용 안 된 origin 에 **프리플라이트뿐 아니라 실제 요청도 403** 을 준다.
그리고 `keep_alive` 가 **비대칭**이다 — 예열 버튼은 30분인데 **답변 생성은 Ollama 기본 5분**이라
예열 후 질문하면 만료가 5분으로 줄어든다(범위 밖이라 코드는 안 고치고 README 에만 적었다).

  포장식품에 그대로 대면 **틀린 근거**다. 2위도 `ALG-007` 로 같은 고시다.
- **Q3** (쿠키 영양성분표) 상위 6개가 전부 **다른 식품유형** 청크다(장류 등) — 경로 라벨도
  `식품등의 표시기준 본문` 이라 화면에서 구별이 안 된다. **S6 가 이 경로 표기를 그대로
  보여 주면 사용자가 검증할 수 없다.**

**인용 유효성 규칙은 이 둘을 통과시킨다.** PRD F5 가 「못 잡는다」고 적은 경로 —
무관 조문을 방패로 인용하는 것 — 이 실제로 재현된다. **S8 의 LLM 근거성 판정이 이걸
잡아야 하고, 못 잡으면 그 사실을 기록해야 한다.**

### 2-5. Q2 는 코퍼스에 근거가 없다 (PRD 9절 수정 필요)

PRD 9절은 「오늘 시행 중인 표시기준 판에 알레르기 근거가 27청크」라고 적었지만, 그 대부분은
**식품유형별 표시사항 목록에 `알레르기 유발물질(해당 경우에 한함)` 이 한 줄 적힌 것**이다.
포장식품의 알레르기 표시 **방법**은 **시행규칙 별표 2** 에 있고, 코퍼스에는 그걸 가리키는
`FLR-020` 만 있다(별표 본문 없음 — S2 는 조문만 받았다). **「어떻게」를 끝까지 답할 근거가 없다.**

→ Q2 의 기대 상태를 **근거약함**으로 둔 근거이고, 코퍼스를 늘릴지(별표 수집)는 별도 판단이다.

### 2-6. 문구를 현실화하면 Q5 가 무너진다 (문구 단독 효과)

초안/확정을 같은 정답으로 대조했다: Q1·Q2·Q3 은 **둘 다 실패**(문구 탓 아님), Q4 는
개선(2위→1위), Q6 은 동일, **Q5 만 1위 → 병합 밖**. 초안 「SNS 협찬 광고도 이 법 적용을
받나요?」는 **조문 어휘를 그대로 쓰고 있었고**, 실제 판매자 말투로 바꾸면 제3조가 사라진다.
평가 문항을 현실 문구로 바꾼 것의 대가이고, 숨기지 않고 기록해 둘 값이 있다.

### 3-1. 🔴 S6 착수 전에 사용자 확인 1건 — 5분

**S6 의 출처 칩 연결 규칙과 S8 의 규칙 배지가 같은 추출기 하나에 얹힌다.** 표기를 모르고

# fundamentals m05 — 포즈 조건으로 이미지 만드는 도구

- 강의노트: `../../AI-Study/notes/aiffel/fundamentals-m05-image-generation.md`

## 과제 개요

ControlNet 의 **Pose 조건**을 써서 "이 자세로 한 장 만들어 줘" 도구를 직접 만든다.
산출물은 **Colab 튜토리얼 노트 한 권**이고, GitHub 에 올려 **링크로 제출**한다.

> 튜토리얼 노트는 강사가 만들어 주지 않는다. 다만 빈 노트에서 시작하라는 뜻은 아니고,
> 「FLUX.2-klein 4B로 마음껏 이미지 만들기」 Colab 노트를 출발점으로 삼아 포즈 조건을 얹는다.

## 1단계 · 포즈 조건을 넣어 도구를 만든다 (30~60분)

참조 사람 사진 한 장 → **OpenPose 로 관절 추출** → ControlNet 전처리로 투입 →
프롬프트와 함께 FLUX.2-klein 4B(또는 비슷한 모델)에.
결과는 **참조 사진과 같은 자세를 한 다른 인물이나 장면**이어야 한다.

노트에는 이 과정이 **처음 보는 사람도 따라 할 수 있게 한 셀 한 셀** 적혀 있어야 하고,
**셀마다 주석으로 '이 셀이 하는 일'** 을 적는다.
모델 로드 / 포즈 추출 / 이미지 생성 / 결과 저장을 각각 한 셀로 나누면 보기 좋다.

## 2단계 · 다른 포즈와 프롬프트로 바꿔 본다 (15분)

같은 포즈에 프롬프트만 바꾸고, 반대로 같은 프롬프트에 다른 포즈 사진을 넣는다.
어느 쪽을 바꿨을 때 크게 달라지는지, 어느 쪽은 잘 안 따라오는지 관찰.
**이 관찰이 노트의 마지막 마크다운 셀에 '무엇을 바꿔 보았고 어떻게 달라졌는가'로 적혀 있어야 한다.**

## 3단계 · GitHub 에 올리고 URL 을 제출한다 (5분)

```
pose-image-tool/
├── README.md          # 도구 설명, 사용법 한 줄
├── pose_tool.ipynb    # Colab 튜토리얼 노트 (핵심)
├── samples/           # 테스트 결과 예시
│   ├── pose_01.png        # 참조로 쓴 포즈 이미지
│   ├── output_01.png      # 같은 자세로 만든 결과
│   ├── pose_02.png
│   └── output_02.png

```

## 과제 개요

**제출은 저장소 링크 하나.**

### 1. 스킬 후보 고르기

"AI 한테 또 이걸 설명하고 있네" 싶은 순간이 후보. 예:
- 코드를 고칠 때마다 우리 팀 린트·컨벤션을 다시 알려 주는 일
- 작업을 끝내고 항상 돌리는 정리 (커밋 메시지·변경 요약)
- 회의록·안내문을 우리 팀 양식으로 바꾸는 일

### 2. 저장소를 만들고 스킬 쓰기

새 GitHub 저장소(예: `my-skills`). Claude Code 기준 경로는
`.claude/skills/<스킬이름>/SKILL.md`, 다른 도구는 각 도구의 스킬 위치.
프론트매터(`name`·`description`) + 본문.

```markdown
---
name: commit-summary
description: 오늘 작업을 우리 팀 커밋 메시지 양식으로 요약할 때 사용
---

# 커밋 메시지 요약

1. `git diff`로 바뀐 부분을 확인한다.
2. 바뀐 것을 주제별로 묶어 한 줄씩 요약한다.
3. 양식은 `[범위] 한 일 (#이슈)` 로 맞춘다.
```

### 3. README 로 '왜' 쓰기

저장소 최상단 `README.md` 에 **"무슨 불편이 있었고, 스킬이 어떻게 없앴는지"** 가 한눈에
들어오게 한 장.

### 4. 올리고 링크 제출

보너스: 친구에게 링크를 주고 "이 스킬 써 봐" 했을 때 **따로 설명하지 않아도 돌아가면 성공.**

## 제출 전 체크리스트

- [ ] `description` 만 봐도 언제 쓰는지 아는가?
- [ ] README 에 '왜'가 **불편에서 해결로** 적혀 있는가?
- [ ] 다른 대화에서 한마디로 발동시켜 보았는가?

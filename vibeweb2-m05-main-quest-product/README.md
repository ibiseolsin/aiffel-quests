## 과제 개요

정해진 예시가 아니라 **내가 만들고 싶은 것**을 만든다. **스택도, 순서도, 어디까지 갈지도 자유.**

**딱 하나: 작게, 한 흐름이 끝까지 굴러가게.**

1. **한 문장으로 정하기** — "[누가] [무엇을] 할 수 있는 [무엇]"
   (예: '동네 모임 주최자가 참가 신청을 받는 페이지')
2. **AI 와 자유롭게 만들기** — 의도 → 확인 → 막히면 다시 지시. 스택·구조는 AI 에게,
   나는 **'무엇을 원하는지'와 '됐는지'만**
3. **내 규칙 하나는 지키게(있다면)** — 정원·선착순·중복 금지·하루 한 번 같은 규칙이
   **실제로 지켜지는지 눈으로 확인**
4. **작동하는 지점에서 제출** — 완성이 아니라 '굴러가는 첫 조각'

## 노드분 제출물 (Main Quest 01 착수분)

- 실행되는 저장소(GitHub 등)나 **배포 주소** (로컬만 됐으면 실행법 + 화면 캡처)
- 내 서비스 **한 문장**
- 오늘 **AI 와 나눈 대화** (가장 효과적이었던 프롬프트 하나는 표시)
- **회고 한 줄**: 무엇을 잘랐나 / 어디서 막혀 어떻게 풀었나 / 다음 한 걸음

> 화면만 떠도, 저장까지 돼도, 배포까지 가도 — **각자 낸 만큼이 성과.**

## 모듈 최종 제출 — Main Quest 01

| 제출물 | 형식 |
|---|---|
| **실행 가능한 웹 서비스** | GitHub 저장소 또는 배포 URL (브라우저에서 동작 확인) |
| **기획 문서 1장** | 마크다운/PDF (서비스 개요·타겟 사용자·해결 문제) |
| **회고록 1장** | 마크다운 (AI 와 협업하며 배운 점·어려웠던 점) |
| **시연 영상** | **3분 이내** (직접 서비스를 시연하며 설명) |

## 평가 루브릭 — 남겨 둘 증거

| 항목 | 비중 | 남겨 둘 증거 |
|---|---|---|
| **도메인 연결성** | 25% | "내 전문 분야의 이 불편을" 으로 시작하는 한 문장 |
| **기능 완성도** | 25% | 다섯 단계 중 도달한 지점 (어디까지 굴러가나) |
| **AI 활용도** | 20% | **AI 와 주고받은 대화 (지우지 말고 그대로 남기기)** |
| **회고 깊이** | 15% | 결정한 것·**참은 것**을 적어 둔 회고 노트 |
| **발표/시연** | 15% | 핵심 가치 **30초**로 말해 보는 연습 |

> **착수 순간부터 제출 기준을 본다.** 다섯 항목의 증거는 따로 챙기려 애쓰지 말고
> **한 문장·대화·결정을 그날 기록으로** 남기면 된다.

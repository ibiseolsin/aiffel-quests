
## 4단계 — 엔진 중립화와 스트리밍 (현재)

이 단계는 **앞 단계에서 정한 세 가지를 갈아엎는다.** 세 결정 모두 앞 번호를 폐기하고
새 규칙으로 대체한다. 앞 단계의 문장이 어딘가에 남아 있어도 **이 절의 규칙이 현재 규칙이다.**

- [ ] **S15. 청크 ID 에 청크 순번을 넣는다**
      한 페이지에 청크가 여러 개일 때 페이지 단위 ID 로는 근거 모달이 어느 청크를 띄울지
      정하지 못했다. 순번을 ID 에 넣어 청크 하나를 정확히 가리키게 한다.
      **D7 (1단계 D2 폐기)**: 청크 ID 는 `{doc}-p{page}-c{idx}` 다.
      `doc` 은 문서 슬러그 문자열, `page` 와 `idx` 는 정수이며 **0 채움을 하지 않는다.**
      예: `make_chunk_id("hr-guide", 3, 5)` → `"hr-guide-p3-c5"`.
      구현 위치: `src/chunk_id.py` 의 `make_chunk_id(doc, page, idx)`.
      완료 기준: 같은 페이지의 청크 두 개가 서로 다른 ID 를 갖는다.

- [ ] **S16. 출력을 줄 단위로 바꾼다**
      배열 한 덩어리는 받는 쪽이 전부 읽을 때까지 첫 행을 처리하지 못한다. 스트리밍을
      붙이려면 행 하나가 도착하는 대로 처리할 수 있어야 한다.
      **D8 (2단계 D5 폐기)**: 결과는 **NDJSON** 이다. 행 하나를 `json.dumps(row,
      ensure_ascii=False)` 로 직렬화해 `"\n"` 으로 잇는다. **마지막 줄 뒤에는 개행을 붙이지
      않는다.** 빈 목록이면 빈 문자열을 돌려준다.
      예: `emit([{"a": 1}, {"b": 2}])` → `'{"a": 1}\n{"b": 2}'`.
      구현 위치: `src/emit.py` 의 `emit(rows)`.
      완료 기준: 돌려준 문자열을 `"\n"` 으로 나눈 각 조각이 `json.loads` 로 파싱된다.

- [ ] **S17. 엔진 주소 환경변수를 중립 이름으로 개명한다**
      로컬 엔진 말고 다른 엔진도 붙일 예정이라 변수 이름이 특정 제품을 가리키면 안 된다.
      **D9 (3단계 D4 폐기)**: 엔진 주소는 환경변수 **`LLM_BASE_URL`** 에서 읽는다.
      **옛 이름은 더 이상 읽지 않는다** — 옛 이름만 있고 새 이름이 없으면 없는 것으로 보고
      `KeyError` 를 낸다. 폴백을 두지 않는다. 조용히 옛 설정으로 붙는 것이 개명의 목적을
      정확히 깨뜨리기 때문이다.
      `load_config(env)` 는 매핑 `env` 를 받아 `{"base_url": <값>}` 을 돌려준다.
      예: `load_config({"LLM_BASE_URL": "http://x"})` → `{"base_url": "http://x"}`.
      구현 위치: `src/config.py` 의 `load_config(env)`.
      완료 기준: 새 이름이 없으면 `KeyError`.

> 4단계 회고: 아직 없음 (진행 중).


## 슬라이스 메모 (1~3단계)

> 각 슬라이스를 끝낼 때 남긴 기록이다. 「미확인」 줄을 먼저 읽는다.

### S1. 저장소 뼈대

- **한 것**: `src/`, `tests/`, `data/` 세 폴더와 `pyproject.toml` 을 만들었다. 패키지 이름은 `regsearch`.
- **실측**: 파일 4개, 테스트 0개 수집 통과
- **미확인**: 파이썬 3.12 이하에서의 동작 — 3.13 만 써 봤다
- **막혔던 것**: `pyproject.toml` 의 `packages` 를 자동 탐색으로 두면 `data/` 까지 잡혀서 명시 목록으로 바꿨다.

### S2. 원문 수집

- **한 것**: PDF 12건을 `pdftotext -layout` 으로 변환해 `data/raw/*.txt` 에 넣었다.
- **실측**: 12건 전부 생성, 빈 파일 0, 총 249KB
- **미확인**: 표가 깨진 3건의 실제 손실량 — 원본 셀 수를 세지 않았다
- **막혔던 것**: `-layout` 없이 돌리면 2단 편집 문서에서 좌우 열이 섞였다. 3건에서 재현돼 플래그를 고정했다.

### S3. 청크 분할

- **한 것**: 문단 경계로 자르고 최대 900자, 겹침 120자. **청크 ID 는 `{doc}-p{page}`** (D2).
- **실측**: 청크 534개, 문서 사이 ID 중복 0
- **미확인**: 청크 크기 900자의 적정성 — 600/900/1200 비교 안 함
- **막혔던 것**: 처음엔 문장 경계로 잘랐는데 「제3조 제1항」이 문장 중간에 끼는 문서가 있어 조항이 두 청크로 갈렸다. 문단 경계로 바꿔 해결.

### S4. 청크 메타

- **한 것**: 문서 제목·페이지·시행일자 3칸을 붙였다. 시행일자 없는 2건은 `null`.
- **실측**: 534개 전부 3칸 채움 또는 명시적 `null`
- **미확인**: 시행일자가 본문에만 적힌 문서가 더 있는지 — 머리말만 봤다
- **막혔던 것**: `null` 을 빈 문자열로 뒀다가 화면에서 「시행일자: 」로 새어 나왔다. 명시적 `null` 로 되돌렸다.

### S5. 청크 저장 형식

- **한 것**: `data/chunks/<doc>.json` 으로 문서별 분리. 한 파일에 몰면 부분 재생성이 안 된다.
- **실측**: 파일 12개, 합계 534
- **미확인**: 파일 12개를 병렬로 다시 만들 때의 경합 — 순차로만 돌렸다
- **막혔던 것**: 문서 슬러그에 하이픈이 있어 파일명은 그대로 썼다. 슬러그에 슬래시가 오면 깨지지만 현재 12건엔 없다.

### S6. 역색인

- **한 것**: 공백·구두점 분리 + 소문자화로 토큰을 만들고 역색인을 세웠다.
- **실측**: 「연차」 질의에서 관련 청크 3위
- **미확인**: 형태소 분석기와의 대조 — 하지 않았다
- **막혔던 것**: 「연차를」과 「연차」가 다른 토큰이 됐다. 2-gram 보조 색인을 얹어 적중이 5/9 → 7/9 로 올랐다.

### S7. BM25 점수

- **한 것**: k1=1.2, b=0.75 기본값. 튜닝하지 않았다.
- **실측**: 점수 단조 감소 정렬, 동점은 청크 ID 사전순으로 결정적
- **미확인**: k1·b 튜닝 이득 — 재지 않았다
- **막혔던 것**: 동점 처리를 안 정해 뒀을 때 같은 질의가 실행마다 다른 순서를 냈다. ID 사전순 타이브레이크를 넣어 고정.

### S8. 질의 확장 보류

- **한 것**: 동의어 사전을 넣으려다 뺐다. 사람이 유지해야 하고 용어 변경을 따라간다는 보장이 없다.
- **실측**: 사전 있음 7/9, 없음 7/9 — 차이 없음
- **미확인**: 사전을 키웠을 때의 이득 — 12항목만 넣어 봤다
- **막혔던 것**: 없음.

### S9. 결과 출력

- **한 것**: 검색 결과를 다음 단계로 넘기는 형식을 정했다. **결과는 JSON 배열 하나** (D5). `json.dumps(rows, ensure_ascii=False)` 한 덩어리.
- **실측**: 출력이 `json.loads` 로 파싱되고 행 수 534 일치
- **미확인**: 행이 수만 개로 늘었을 때의 메모리 — 527 에서만 봤다
- **막혔던 것**: `ensure_ascii=True` 기본값 때문에 한글이 전부 이스케이프돼 파일이 2.3배가 됐다. `False` 로 고정.

### S10. 중복 제거

- **한 것**: 본문 해시로 완전 중복만 지웠다. 근사 중복은 손대지 않았다.
- **실측**: 완전 중복 7건 제거, 527개 남음
- **미확인**: 근사 중복의 양 — 재지 않았다
- **막혔던 것**: 해시를 본문+메타로 잡았더니 같은 본문이 페이지만 달라 중복으로 안 잡혔다. 본문만으로 바꿨다.

### S11. 평가 세트

- **한 것**: 질의 9개와 정답 청크 ID 목록을 손으로 만들었다. 정답이 여럿인 질의 4개.
- **실측**: 9개 질의 전부 정답 청크가 코퍼스에 실존
- **미확인**: 질의 9개가 실사용 분포를 대표하는지 — 사람이 골랐다
- **막혔던 것**: 정답을 청크 ID 로 적었더니 S3 재생성 때 ID 가 흔들려 정답이 어긋났다. 재생성이 결정적임을 먼저 확인한 뒤 다시 적었다.

### S12. 기준선 측정

- **한 것**: 적중 7/9. 실패한 둘은 표에 있던 내용을 묻는 질의.
- **실측**: 적중 7/9, 질의별 순위 기록
- **미확인**: 표 2건은 **재현 자료가 없어 영원히 미확인**
- **막혔던 것**: 없음.

### S13. LLM 엔진 연결

- **한 것**: 로컬 엔진에 HTTP 로 붙였다. **엔진 주소는 환경변수 `OLLAMA_URL`** (D4). 기본값 없음, 없으면 즉시 오류.
- **실측**: 환경변수 있으면 붙고 없으면 오류 — 둘 다 확인
- **미확인**: 다른 엔진에서의 동작 — 하나만 붙였다
- **막혔던 것**: 기본값을 `http://localhost:11434` 로 뒀을 때 변수 오타를 조용히 넘겨 엉뚱한 데로 붙었다. 기본값을 없앴다.

### S14. 프롬프트 조립

- **한 것**: 상위 5개를 근거로 붙이고 「자료에 없으면 없다고 답하라」를 넣었다.
- **실측**: 조립된 프롬프트에 상위 5개 청크 ID 전부 포함
- **미확인**: 자료 밖 내용 생성 감소량 — 수치 없음
- **막혔던 것**: 근거를 점수 순으로 붙였더니 같은 문서 청크가 연속으로 와서 다양성이 낮았다. 문서당 최대 2개로 제한.

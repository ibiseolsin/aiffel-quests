## 과제 개요

코드 구현 과제가 아니다. **지금 쓰는 도구의 불편 하나를 반증 가능한 가설로 바꾸고, 한 항목만
조작하는 실험을 설계해 GitHub 저장소에 Markdown 보고서로 제출한다.**

기준 도구는 **실제로 사용하고 있는 것** 가운데 하나 — 원문은 Claude Code, opencode,
Antigravity 를 예로 든다.

## 원문 기준 요구사항

### 1단계 — 불편을 구체적으로 적는다

최근 과업에서 반복해 멈추거나 되돌린 장면 하나.

- ❌ "도구가 불편합니다"
- ✅ 어떤 과업에서 **어떤 입력 뒤에** 무엇이 지연되거나 잘못되었는지

그리고 **이 불편이 정말 하네스 기능에서 온 것인지 의심한다** — 모델 선택, 과업 난이도, 저장소
상태, 네트워크, 자신의 요청 문장이 원인일 수 있다.

### 2단계 — 반증 가능한 개선 가설로 바꾼다

결과가 반대로 나오면 **틀렸다고 말할 수 있어야** 한다.

- 예: "승인 대기로 과업이 멈췄다" → "권한 규칙의 범위를 조정하면 완료 시간이 줄어든다"
- 인용하는 근거에 **`[학술]` / `[벤더]` / `[공식 문서]` 등급을 표기**한다
- **벤더 자체 보고는 독립 비교가 아니라는 점**도 보고서에 남긴다

### 3단계 — 한 항목만 조작하는 실험을 설계한다

| 구분 | 요구사항 |
|---|---|
| **고정** | 모델, 과업셋, 토큰 또는 시간 예산 |
| **조작** | 관측 개수 N / 편집 포맷 / 권한 정책 / 메모리 표현 중 **하나만** |
| **측정** | 해결률 + **토큰 + 승인 횟수 + 시간** |
| **사전 판정식** | **결과를 보기 전에** 어떤 결과면 지지하고 어떤 결과면 버릴지 수치와 함께 |
| **반론** | 예상 반론 하나 이상 + 그 반론과 가설을 구분할 통제 조건 |

### 4단계 — GitHub 저장소에 Markdown 보고서 제출

- 저장소 `README.md` 에 **가설 → 실험 설계 → 결과 → 다시 검토할 조건** 순서
- 실행했다면 **before / after trace** 또는 그에 해당하는 기록을 링크하거나 넣는다
- **실행하지 못했으면 그 이유와 사전 판정식**을 남긴다
- **불편의 진짜 원인이 선택한 하네스 기능이었는지 돌아보는 문단**을 넣는다
- 가설과 다른 결과가 나왔으면 감추지 않고 **무엇이 원인 설명을 약하게 만들었는지 + 다음 실험에서
  고정하거나 바꿀 조건**을 적는다
- 마지막에 **선택 도구 / 선택 근거 / 확인한 경계 / 미확인 사항 / 재검토 조건**

## 원문의 진행 예시 (그대로 따를 필요는 없음)

**가설**: 같은 과업을 다시 풀 때 첫 시도의 기록을 `notes/` 에 남기고 다음 요청에서 참조하게 하면,
기록 없이 시작할 때보다 두 번째 시도가 빠르고 정확해진다. (커뮤니티 용어로 **컴파운드 엔지니어링**)

**fixture 3개** — 입력 파일을 미리 만들고 **내용을 바꾸지 않는다**:

| 테스크 | 내용 |
|---|---|
| `parse-log` | `sample.log` 에서 오류만 골라 표로 정리하는 `parse.py` 작성 |
| `refactor-util` | `util.py` 의 함수 3개에 타입 힌트와 독스트링 추가 |
| `fix-failing` | `test_me.py` 의 실패 2건을 통과하도록 수정 |

| 구분 | 예시 내용 |
|---|---|
| 고정 | 같은 도구·모델·세 테스크·작업 폴더 |
| 조작 | 첫 시도 후 `notes/` 에 접근법·주의점을 남기고 참조 **vs** 기록 없이 새로 시작 |
| 측정 | 두 번째 시도의 소요 시간, 수정 횟수, 테스트 통과까지의 시도 수, 토큰 |
| 사전 판정식 | 기록 조건이 **세 테스크 중 두 개 이상에서 시간·시도 수 모두 적으면 지지**, 그 외 기각 |

원문은 실험 기록 파일명을 `experiment-01.md` 로 제시하고, 그 안에 **가설 → 배경 근거(등급 표기)
→ 설계 표 → 실행 기록 → 결과 표 → 판정 결과 → 다음 실험 계획** 순서를 적었다.

- [ ] 맺음: 선택 도구 / 선택 근거 / 확인한 경계 / 미확인 사항

# 트레이스 — Q1 정상 경로 (읽기 1회)

> ## 실측이 아니라 설계상 기대치다
> 모델을 돌려서 얻은 기록이 **아니다.** 설계가 "이렇게 남아야 한다"고 정한 관찰 항목을
> 미리 채운 것이다 (PLAN D7, PRD 7절 "안 할 것"). 이 저장소에 실행 기록은 없다.
>
> 양식과 값 표기 규칙은 [`design-packet.md` 6절](../../design-packet.md) 이 정한다.
> 대응 문항: 패킷 5.2 **Q1** (`UC1` · 정상 경로).
> **⟨…⟩ 로 감싼 값은 도구가 코퍼스에서 채우는 자리**이고, 감싸지 않은 값은 정의서 9절이
> 코퍼스를 읽어 확인한 값이다 (패킷 6.3).

---

## 1. 요청

| | |
|---|---|
| 사용자 발화 | "상세페이지에 '다이어트에 좋은 곤약젤리'라고 쓰려는데 써도 되나요" |
| 세션 상태 | 첫 턴. 앞선 도구 호출 없음, `evidence` 없음 |
| 사용자가 제시한 것 | **문구** — "다이어트에 좋은" (PLAN D3 의 가르는 질문) |
| 신뢰 등급 | 검토 대상 문구 = **데이터**. 과업 지시와 분리해 전달 (패킷 2.4 입력 층) |

## 2. 선택한 도구

| | |
|---|---|
| 부른 도구 | `search_expression_rule` **1회** |
| 걸리는 '쓰는 때' | 정의서 2절 ③ "쓰려는(또는 이미 쓴) 문구를 제시하고 그 문구를 써도 되는지 물을 때" |
| 부르지 않은 도구 | `list_mandatory_labels` — "곤약젤리"라는 제품 이름이 왔지만 물은 것이 "무엇을 적어야 하나"가 아니다 (정의서 3절 ③ 은 유형 제시와 그 물음이 **함께** 성립해야 걸린다) · `get_article` — 조문 번호가 없다 · `file_review_request` — 읽기 도구를 아직 부르지 않았다 (정의서 5절 ③ '안 쓰는 때') |
| 한 턴 읽기 호출 수 | **1 / 4** (패킷 2.2 상한 4회) |

## 3. 인자

| 인자 | 값 | 근거 |
|---|---|---|
| `expression` | `"다이어트에 좋은"` | 발화에서 그대로. 200자 이내 (정의서 2절 ④). 문장 전체가 아니라 **확인하려는 한 구절**로 좁혔다 |
| `surface` | `"광고"` | 상세페이지 문구이므로. **도구 선택을 바꾸지 않는다** — `limits` 문구만 바꾼다 (정의서 7.1) |
| `productContext` | `"곤약젤리"` | 100자 이내. 영양강조표시 판단의 전제를 좁힌다 |
| `maxHits` | `3` | 기본값 |
| 추측으로 채운 인자 | **없음** | 빈 필수 인자가 없으므로 되묻기(`MISSING_EXPRESSION`)가 걸리지 않는다 |

## 4. 반환 근거

`ok`=`true` · `code`=`"OK"` · `coverage.level`=`"full"` · `treatedAsData`=`true`.
`hits[]` **1건** (`maxHits` 3 이내).

| 필드 | 값 | 이 답의 어디에 쓰이나 |
|---|---|---|
| `hits[0].citation.lawName` | `부당한 표시ㆍ광고 내용 기준` | 최종 답 2번 칸 |
| `hits[0].citation.kind` | `고시` | 최종 답 2번 칸 |
| `hits[0].citation.path` | `⟨제2조 해당 호⟩` — 걸린 금지유형의 호 | 최종 답 2번 칸 |
| `hits[0].citation.url` | `⟨law.go.kr 링크⟩` | 최종 답 2번 칸 |
| `hits[0].citation.effectiveDate` / `inForce` | `⟨코퍼스 시행일⟩` / `true` | 최종 답 2·4번 칸 (정의서 1.1 — 시행일 없는 인용은 확인할 수 없는 인용이다) |
| `hits[0].excerpt` | `⟨400자 이내 발췌⟩`, 자른 자리는 `…` | 최종 답 1·2번 칸 |
| `hits[0].why` | `⟨이 기준이 걸린 이유 한 문장⟩` | 최종 답 1번 칸 |
| `hits[0].basisKind` | `"금지유형"` | 최종 답 1번 칸 — 정의가 아니라 금지유형에 걸렸다는 뜻 |
| `hits[0].crossRef` | `null` | 다른 문서를 가리키기만 하는 기준이 아니므로 `coverage.level`=`"full"` (가리키기만 했다면 `CROSS_REF_UNRESOLVED` → 보류, 3.2 #14) |
| `coverage.note` | `⟨범위 메모⟩` | 최종 답 3번 칸 |
| `limits[]` | "걸리는 기준을 찾은 것이고 개별 제품의 적법 여부는 판단하지 않았습니다" 외 | 최종 답 3번 칸 |
| `corpusAsOf` / `corpusAgeDays` | `2026-08-28` / `3` | 최종 답 4번 칸 |

**반환에 없는 것** — 청크 id, 검색 점수, 코퍼스 파일 경로, 조문 전문 일괄 (정의서 1.3).
도구가 주지 않으므로 이 기록에도, 최종 답에도 나올 수 없다.
**`pendingAmendment` 는 이 도구의 반환 필드가 아니다** (정의서 4절 ⑤ `get_article` 전용).
시행 예정 개정은 여기서 말하지 않는다.

## 5. 최종 답 (패킷 4.2 다섯 칸)

| # | 칸 | 내용 |
|---|---|---|
| 1 | 답 요약 | "'다이어트에 좋은'은 부당한 표시·광고 금지 기준에 **걸리는 표현으로 확인됩니다.** 어느 기준에 걸리는지는 아래 조문에 있습니다." |
| 2 | 근거 인용 | `부당한 표시ㆍ광고 내용 기준` · 고시 · `⟨제2조 해당 호⟩` · `⟨URL⟩` · 시행 `⟨시행일⟩` (시행 중) — 발췌 `⟨400자 이내⟩` |
| 3 | 말할 수 없는 것 | "이 답은 걸리는 **기준 조문을 찾은 것**이고, 이 문구를 실제로 썼을 때 적법한지는 판단하지 않았습니다. 표현을 바꿨을 때의 결과도 이 답에 없습니다." |
| 4 | 시점 | "자료 수집일 2026-08-28 (3일 전) 기준입니다." |
| 5 | 다음 행동 | **없음.** 되묻기도 이관 제안도 하지 않는다 |

**쓰지 않은 문장** — "괜찮다 / 문제없다 / 합법이다 / 위법이다", 인용 없는 규정 서술,
실패 코드 문자열 (패킷 4.3). 기준을 못 찾았더라도 `NO_MATCH` 는 **보류**이지 허가가 아니다
(3.2 #4, 정의서 2절 ⑥).

## 6. 중단·이관 사유

**중단 없음 · 이관 없음.** 여덟 조건을 한 줄씩 확인한 결과다 (패킷 3.4).

| 조건 | 성립? | 왜 |
|---|---|---|
| S1 같은 실패 코드 2회 연속 | 아니오 | 실패 코드가 0회 (`code`=`"OK"`) |
| S2 한 턴 읽기 호출 4회 초과 | 아니오 | 1회 |
| S3 되묻기 2회 연속 무해결 | 아니오 | 되묻기 0회 — 필수 인자가 다 찼다 |
| S4 근거 둘이 어긋남 | 아니오 | `hits[]` 1건, 어긋날 짝이 없다 |
| S5 승인·규칙 우회 요청 | 아니오 | 발화에 우회 요청이 없다 |
| S6 승인 거부·만료 | 아니오 | 쓰기 도구를 부르지 않았다 |
| S7 `CORPUS_UNAVAILABLE` 세션 2회째 | 아니오 | 코퍼스를 읽었다 |
| S8 확정 판단 3회째 요구 | 아니오 | 첫 턴, 확정 요구 0회 |

**이 기록이 다음 턴에 남기는 것** — `evidence` 로 쓸 수 있는 인용 튜플 1건. 사용자가 여기서
확답을 요구하면 [Q6 기록](q6-handoff-approval.md), 우회를 요구하면
[Q7 기록](q7-bypass-refused.md) 으로 이어진다. 두 기록 모두 이 턴의 인용을 근거로 쓴다.

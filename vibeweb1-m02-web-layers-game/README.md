# vibeweb1 m02 — 작은 웹 게임 만들어 배포하기

- 코스: 바이브 코딩으로 웹 만들기_Agt1
- 강의노트: `../../AI-Study/notes/aiffel/vibeweb1-m02-web-layers-game.md`
- 커리큘럼: LMS 노드 링크는 노트 프론트매터의 `lms_url` 참고

## 과제 개요

한 화면에서 끝나고 클릭/키보드로 조작하는 **작은 게임** 하나를 만들어 GitHub Pages 로 배포하고,
**배포된 링크 하나**를 제출한다.

예시: 가위바위보 · 숫자 맞히기 · 반응속도 테스트 · 두더지 잡기 · 카드 뒤집기
(목록 밖의 것이면 더 좋다)

## 원문 기준 요구사항

- 파일은 `index.html`, `styles.css`, `script.js` **세 개로 나눈다**
- 규칙과 끝나는 조건을 **내가 직접 적고**, AI 가 임의로 바꾸지 않았는지 확인한다
- 모바일에서도 조작하기 편한 크기, 상태가 **색과 문구로 함께** 보인다
- 끝나는 조건이 되면 **결과 + 다시하기 버튼**
- **GitHub Pages** 로 배포

## 제출물

배포된 게임 링크 하나 (예: `https://내아이디.github.io/my-game/`)

## 제출 전 체크리스트

- [ ] 링크를 **새 창(또는 시크릿 창)** 에서 열었을 때 게임이 뜬다
- [ ] 내 컴퓨터가 아니라 **그 웹 주소에서** 조작이 실제로 동작한다
- [ ] **휴대폰**으로 열어도 플레이할 수 있다
- [ ] 링크를 **동료에게 보냈을 때도** 열린다

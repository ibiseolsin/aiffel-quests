# fundamentals m07 — 공개할 수 있는 공간을 골라 올리기

- 코스: AI의 이해와 사용_Agt1
- 강의노트: `../../AI-Study/notes/aiffel/fundamentals-m07-spatial-ai.md`

## 과제 개요

**밖에서 공간을 하나 골라** 같은 길(촬영 → 점 → 알갱이 → 줄여서 올리기)로 올리고 주소를 제출한다.
페이지는 이미 있으니 새로 만들 것이 없다. 바뀌는 것은 **찍는 자리와 그 자리를 고르는 판단.**

## 1단계 — 찍어도 되는 곳을 고른다

**두 조건을 동시에** 만족해야 한다 (하나만 맞으면 과제가 안 끝난다).

**① 남에게 보여도 되는 곳** — 화면에 들어오면 곤란한 것: 지나가는 사람의 얼굴, 차 번호판,
현관 문패와 호수, 가게 안 손님, 책상 위 서류. 촬영을 제한하는 곳(미술관·공연장·일부 매장)은
안내판을 보거나 직원에게 묻는다. 회사 건물이면 보안 규정을 먼저.

**② 시차가 쌓이는 곳** — 벽과 물건이 가까워 몇 걸음에 화면이 크게 밀리고, 무늬가 넘쳐야 한다.
**전망대에서 먼 풍경을 찍으면 이 둘이 한꺼번에 사라진다.**

| 고를 만한 곳 | 왜 나오나 | 조심할 것 |
|---|---|---|
| 공원의 조형물이나 정자 | 둘레를 한 바퀴 돌 수 있어 시차가 크게 쌓임 | 받침의 이름, 옆 벤치의 사람 |
| 벽화·간판이 있는 좁은 골목 | 벽이 가까워 크게 밀리고 무늬가 많음 | 주택가면 문패와 호수 |
| 야외 계단참과 난간 | 형태가 뚜렷하고 그늘과 빛이 갈려 무늬가 삶 | 오르내리는 사람 |
| 열려 있는 로비나 통로 | 실내라 빛이 고르고 벽이 가까움 | 촬영 정책과 사람 |

**안 나오는 자리**: 매끈한 유리벽, 잔잔한 물, 하늘, 고르게 깔린 잔디.
**밖에서 새로 생기는 함정**: 움직이는 것(사람·나뭇잎·물) / 빛(해를 마주 보면 하얗게 날아감 —
해를 등지고 돌고, **흐린 날이 오히려 고르게 나온다**).

## 2단계 — 찍어서 알갱이 파일까지

걸어 다니면서 **15~20초, 천천히, 1080p**. 대상 하나를 골랐으면 둘레를 한 바퀴, 감싸인 자리면
안에서 크게 원을 그리며. 그다음은 앞 노트를 처음부터 다시 돌린다.

> **카메라가 퍼진 정도가 0.1 아래면 화면을 열어 볼 것도 없이 몇 걸음 더 옮겨 다니며 다시 찍는다.**

## 3단계 — 형식 셋으로 뽑아 견준다

> 내 스플랫 `.ply` 를 형식 셋으로 각각 변환하고 비교표를 만들어 주세요.
>
> - `npx -y @playcanvas/splat-transform@latest` 를 씁니다. 설치는 하지 않습니다. **`-w` 를
>   붙여 덮어쓰게** 해 주세요.
> - `.compressed.ply` 와 `.sog` 와 `.spz` 셋으로 각각 변환해 주세요.
> - 형식마다 **파일 크기(바이트), 변환 시간, 알갱이 개수**를 표로 뽑고,
>   **파일 크기 ÷ 알갱이 개수**를 한 칸 더 넣어 주세요.
> - 앞서 만든 페이지가 **파일을 화면에 끌어다 놓으면 그것으로 다시 그리게** 고쳐 주세요.
>   확장자를 형식 이름으로 옮기는 대응표가 셋 다 있어야 합니다.

**세 파일에서 알갱이 개수가 같아야 한다.** 다르면 형식을 바꾼 것이 아니라 **솎아 낸 파일과
바꿔 든 것.**

## 4단계 — 저장소에 올리고 주소를 제출

```
my-open-space/
├── index.html      앞에서 만든 페이지 그대로
├── scene.sog       줄인 알갱이 파일
├── README.md       아래 양식
└── shots/
    └── viewer.png  화면을 갈무리한 것 한 장
```

**README 양식** (원문 그대로)

## 제출물

**두 줄** — Pages 주소 한 줄 + 저장소 주소 한 줄.
보내기 전에 **주소 뒤에 `/scene.sog` 를 붙여 파일이 직접 내려오는지 확인.**
(100MiB 를 넘는 파일은 애초에 안 올라간다.)

## 채점 기준 (셋)

- [ ] **주소가 열리고 남에게 보낼 수 있는가** — 링크를 받은 사람의 폰에서 화면이 뜨는지, 그
      화면에 남의 얼굴이나 문패가 안 들어갔는지. **고른 근거가 README 에 한 줄** 있어야 한다
- [ ] **눈이 아니라 숫자로 판정했는가** — 카메라가 퍼진 정도, 알갱이당 바이트, 형식별 크기와
      알갱이 개수가 README 에. **`.ply` ÷ 알갱이 개수가 68이면 각도별 색이 빈 것이고, 재서 채운
      파일은 그것이 정상**
- [ ] **안 나온 자리를 설명할 수 있는가** — 검은 얼룩이 왜 거기 남았는지, 앞뒤가 뒤집힌다면
      무엇이 어긋난 것인지를 **시차와 정렬 순서 같은 낱말로**

> **끝까지 못 가도 괜찮습니다.** 주소에 이미 올라간 것은 그대로 남고, 어디서 왜 막혔는지를
> 설명할 수 있으면 그것으로 충분합니다.
